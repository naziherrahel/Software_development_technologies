## Instructions

### Step 1 — Clone the Repository

Clone this repository to your local machine.

Do not modify any files yet.

---

### Step 2 — Inspect the Files

Before running the application:
- open `app.py`,
- open `requirements.txt`,
- read this README fully.

Try to understand **what the application expects**, even if it is not explicitly documented.

---

### Step 3 — Attempt to Run the Application

Use Python to run the application.

You may:
- install dependencies,
- try different Python versions,
- search error messages online.

You may not:
- rewrite application logic,
- remove code that causes errors.

The objective is **observation and documentation**, not success.

---

## Documentation Requirement

While attempting to run the application, maintain a deployment log.
