# Lab 2 — DevOps Fundamentals


---

## Overview

This repository contains a **small Python web application**.

Your task is **not** to develop new features.
Your task is to **attempt to run the application**, observe what happens, and document the issues you encounter.

The application is intentionally **not production-ready**.

---

## Learning Goals

By completing this lab, you should be able to:

- recognize common deployment problems,
- understand how environment differences affect software behavior,
- explain why DevOps practices are necessary in modern software development.
